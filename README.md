# Shapes Around Us – Mia's Shape Adventure

A story-based shape-learning game for Class 3. Single-file HTML, no build step, no dependencies.

- **Level 1** – The Square (find the Mayor's photo frame)
- **Level 2** – The Mystery of the Missing Magic Wheel (Circle)
- **Level 3** – The Secret of Triangle Mountain (Triangle) + Tangram treasure lock

## Run
Open `index.html` in any modern browser.

## Host free on GitHub Pages
Repo **Settings → Pages → Deploy from branch → `main` / root**.
